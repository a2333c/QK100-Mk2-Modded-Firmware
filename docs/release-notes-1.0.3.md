# QK100 Mk2 工具与固件 1.0.3

## 本次发布

Windows x64 便携刷写应用，内置官方主控 v137、修改版主控 v137、官方屏幕 v120、修改版屏幕 v20，以及官方与可选半透明图包。

主控修改版让轴灯和 Logo 灯组切换时保留亮度。屏幕修改版增加数字电量和 NUM 状态，修正背景透明度及时间布局。两个固件独立使用，屏幕 v20 无需额外图包。可选 alpha128 图包只调整两项图片资源。

## 下载和使用

下载 `QK100-Firmware-Updater-1.0.3.exe`，使用有线连接，并关闭占用设备的其他驱动页面。固件已内置，单独提供的 BIN 文件供校验或兼容升级通道使用。完整操作、前后实拍和回退方法见仓库 README。

屏幕连接需要先选择普通键盘，启用屏幕 USB，再点击“选择 LCD 屏幕”。刷图包时，应用会先写图包，再写当前选中的屏幕程序。开始升级后请保持连接和供电。

## 验证和限制

36 项应用测试通过，7 项打包资源与运行源码核验通过。3 个修改版从官方文件重建后逐字节一致。公开整理期间没有再次刷写设备。

此版本没有修改 LCD 背光或面板刷新率，没有自动设置动画 15 fps，也未测量省电效果。NUM 反向与独立 LED 点阵灯联动现象没有作为已修复功能发布。文件哈希见 `SHA256SUMS.txt`。
